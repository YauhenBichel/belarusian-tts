# Security

The server binds to `127.0.0.1` by default and has no authentication: put it behind your own gateway
if it must be reachable from other machines. It only accepts text and returns audio; request size is
capped at 1000 characters.

To report a vulnerability, please use GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability) rather than a public issue. You will get an answer within a week.
